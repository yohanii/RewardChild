# RewardChild UI·세계관 콘셉트

## 문서 목적

이 문서는 RewardChild의 UI 리디자인과 브랜딩에 사용할 중세 판타지 세계관의 기준을 정리한다. 향후 화면 디자인, 캐릭터 제작, 문구 작성, 공통 컴포넌트 설계 시 본 문서를 공통 기준으로 활용한다.
RewardChild_UI_Worldbuilding_Concept
현재 확정된 방향과 아직 결정되지 않은 항목을 구분하며, 미정인 색상·폰트·세부 컴포넌트 사양은 모두 **추후 확정**으로 표기한다.

## 1. 전체 디자인 방향

- 전체 콘셉트는 **중세 판타지 게임형 UI**로 한다.
- 사용자가 일상에서 수행하는 보상 활동을 판타지 세계의 퀘스트, 의뢰, 상점 거래, 은행 업무로 재해석한다.
- 자녀는 퀘스트를 수행하는 용사, 부모는 의뢰와 상점을 운영하는 상인, 은행 기능은 장부와 금화를 관리하는 은행가의 역할로 표현한다.
- 단순히 중세풍 장식을 더하는 데 그치지 않고, 앱의 기능과 세계관 속 역할이 자연스럽게 연결되도록 설계한다.
- 전반적인 분위기는 게임처럼 흥미롭고 몰입감 있게 구성하되, 자녀가 친근하게 느낄 수 있는 귀여움을 유지한다.
- 부모가 사용하는 관리 기능은 세계관을 유지하면서도 정보 확인과 조작이 명확하도록 설계한다.

### 현재 확정된 핵심 키워드

- 중세 판타지
- 모험과 퀘스트
- 용병술집과 의뢰 게시판
- 상점과 거래
- 은행과 장부
- 귀여운 동물 캐릭터
- 역할별 성격과 공간의 구분

### 추후 확정 항목

- 메인·서브 색상: **추후 확정**
- 성공·경고·오류 등 상태 색상: **추후 확정**
- 폰트와 타이포그래피 체계: **추후 확정**
- 일러스트의 구체적인 화풍과 묘사 수준: **추후 확정**
- 화면별 배경의 밝기와 질감 강도: **추후 확정**
- 애니메이션과 효과음 사용 여부: **추후 확정**

## 2. 캐릭터 정의

### 2.1 자녀 캐릭터 — ENFP 리트리버 용사

- 종족 및 역할: 리트리버 용사
- 성격 유형: ENFP
- 클래스: 갑옷을 입은 전사 클래스
- 핵심 성격:
  - 귀엽고 활발하다.
  - 탐험심과 호기심이 많다.
  - 새로운 퀘스트와 보상에 적극적으로 도전한다.
- 세계관 내 역할:
  - 의뢰를 수락하고 퀘스트를 수행하는 주인공이다.
  - 완료한 임무를 보고하고 보상을 받는다.
  - 획득한 재화로 상점의 물품을 구매한다.
- 시각적 특징:
  - 리트리버 특유의 밝고 친근한 인상
  - 귀여운 비율의 갑옷과 전사 장비
  - 모험을 기대하는 생동감 있는 표정과 자세
  - 갑옷·무기·장비의 구체적인 디자인: **추후 확정**

### 2.2 부모 캐릭터 — ISFJ 검은 고양이 상인

- 종족 및 역할: 검은 고양이 상인
- 성격 유형: ISFJ
- 핵심 성격:
  - 차분하고 꼼꼼하다.
  - 용사를 돌보고 필요한 일을 세심하게 관리한다.
  - 거래와 보상 정산을 안정적으로 운영한다.
- 세계관 내 역할:
  - 판타지 상점을 운영한다.
  - 용병인 자녀 용사를 고용해 퀘스트를 맡긴다.
  - 퀘스트 수행과 보상 과정에서 중간 수수료를 얻는 상인이다.
  - 의뢰 등록, 완료 승인, 보상 지급, 상점 운영 등 부모 기능을 담당한다.
- 시각적 특징:
  - 검은 고양이의 차분하고 영리한 인상
  - 상점 주인임을 보여주는 복장과 소품
  - 믿음직하면서도 친근한 분위기
  - 복장·장부·동전 주머니 등 세부 소품: **추후 확정**

### 2.3 은행 캐릭터 — ISTJ 안경 쓴 너구리 은행가

- 종족 및 역할: 안경 쓴 너구리 은행가
- 성격 유형: ISTJ
- 핵심 성격:
  - 유식하고 신중하다.
  - 숫자와 계산에 강하다.
  - 금화와 거래 기록을 철저하게 관리한다.
- 세계관 내 역할:
  - 코인과 자산을 관리한다.
  - 충전, 환전, 거래내역, 장부 확인과 같은 은행 기능을 안내한다.
  - 정확하고 믿을 수 있는 금융 관리자의 인상을 제공한다.
- 시각적 특징:
  - 지적인 인상을 주는 안경
  - 장부, 주판, 깃펜, 금화 등 계산과 기록을 상징하는 소품
  - 반듯하고 정돈된 자세와 표정
  - 의상과 은행 내부 소품의 구체적인 디자인: **추후 확정**

## 3. 화면별 세계관

### 3.1 Home 화면 — 모험의 거점

- 전체 기능으로 이동하는 모험의 출발점이자 현재 상태를 확인하는 거점으로 해석한다.
- 사용자 역할에 따라 자녀 용사 또는 부모 상인의 성격이 자연스럽게 드러나도록 구성한다.
- 진행 중인 퀘스트, 보유 재화, 최근 활동 등의 핵심 정보를 게임의 상태판처럼 보여줄 수 있다.
- 구체적인 공간 배경과 정보 배치: **추후 확정**

### 3.2 Quest 화면 — 중세 여관·용병술집

- 공간 콘셉트는 **중세 여관 또는 용병술집**이다.
- 벽에 설치된 게시판에 여러 장의 양피지 의뢰서가 붙어 있는 모습을 기본 이미지로 한다.
- 각 퀘스트 카드는 게시판에 부착된 개별 의뢰서처럼 표현한다.
- 퀘스트 생성은 새로운 의뢰를 게시하는 행위로 해석한다.
- 자녀의 퀘스트 수락과 완료 보고, 부모의 승인과 반려는 용병 의뢰 절차처럼 연결한다.
- 양피지의 형태, 압정·밀랍 인장 등의 장식, 게시판 재질과 카드 상태 표현: **추후 확정**

### 3.3 Shop 화면 — 중세 판타지 상점

- 공간 콘셉트는 **검은 고양이 상인이 운영하는 중세 판타지 상점**이다.
- 배경과 진열 공간에는 물약, 무기, 잡화 등 판타지 상점의 상품이 놓여 있는 분위기를 사용한다.
- 실제 보상 상품은 세계관 속 상점 물품처럼 진열하고 구매하도록 구성한다.
- 부모는 상점 운영자, 자녀는 획득한 재화로 물품을 구매하는 용사의 역할을 갖는다.
- 상품 카드, 진열대, 가격표, 구매 버튼의 구체적인 스타일: **추후 확정**

### 3.4 Bank 화면 — 금화 보관소와 장부실

- 공간 콘셉트는 **안경 쓴 너구리 은행가가 관리하는 중세 은행 또는 장부실**이다.
- 금화, 금고, 장부, 깃펜, 주판 등 계산과 자산 관리를 상징하는 요소를 활용할 수 있다.
- 잔액은 보유 금화, 충전은 금화 환전 또는 입금, 거래내역은 장부 기록으로 해석한다.
- 신뢰감과 정확성이 중요하므로 다른 화면보다 정돈된 인상을 유지한다.
- 은행 배경, 자산 표시 방식, 재화별 시각적 구분: **추후 확정**

### 3.5 Settings·Relation 화면 — 길드 관리 영역

- 가족 관계 연결과 설정 기능은 세계관 속 길드원 또는 동료 관리의 개념으로 확장할 수 있다.
- 다만 실제 기능의 의미가 모호해지지 않도록, 세계관 용어와 일반적인 설명을 함께 사용하는 방안을 고려한다.
- 구체적인 세계관 명칭과 화면 표현: **추후 확정**

## 4. 용어 치환 예시

다음 표현은 세계관 적용을 위한 예시이며, 실제 UI에 사용할 최종 문구는 사용성 검토 후 확정한다.

| 기존 기능·용어 | 세계관 용어 예시 | 의미 |
| --- | --- | --- |
| 퀘스트 등록 | 의뢰 등록 / 의뢰서 게시 | 부모 상인이 새로운 일을 게시함 |
| 퀘스트 수락 | 의뢰 수락 | 자녀 용사가 수행할 임무를 받음 |
| 완료 요청 | 의뢰 완료 보고 | 자녀 용사가 임무 완료를 알림 |
| 승인 | 의뢰 완료 승인 | 부모가 결과를 확인하고 완료 처리함 |
| 반려 | 의뢰 보완 요청 | 완료 조건이 부족하여 다시 수행하도록 안내함 |
| 보상 지급 | 의뢰 보상 정산 | 완료된 임무의 재화를 지급함 |
| 상점 구매 | 상점 물품 구매 | 획득한 재화로 보상 상품을 구매함 |
| 코인 충전 | 금화 충전 / 금화 환전 | 사용할 재화를 추가함 |
| 잔액 | 보유 금화 | 현재 보유한 재화를 표시함 |
| 거래내역 | 장부 / 거래 장부 | 재화의 증가와 사용 기록을 확인함 |
| 가족 연결 | 길드 연결 / 동료 연결 | 부모와 자녀의 관계를 연결함 |
| 연결 요청 | 길드 초대 | 새로운 가족 관계 연결을 요청함 |

### 용어 적용 원칙

- 세계관 용어만으로 기능을 이해하기 어려운 경우 일반 용어를 보조 설명으로 함께 표시한다.
- 자녀 화면은 모험과 성취감을 높이는 표현을 적극적으로 사용할 수 있다.
- 부모 화면은 재미를 유지하되 승인, 반려, 금액, 상태 등 핵심 정보가 분명해야 한다.
- 최종 용어와 마이크로카피: **추후 확정**

## 적용 원칙

1. 세계관은 기능 이해를 돕는 방향으로 사용하며, 핵심 정보와 조작을 가리지 않는다.
2. 자녀에게는 모험과 성취의 재미를, 부모에게는 관리의 명확성과 신뢰감을 제공한다.
3. 캐릭터의 성격, 역할, 대사는 모든 화면에서 일관되게 유지한다.
4. 기존 비즈니스 흐름은 유지하고, UI 표현과 용어를 세계관에 맞게 발전시킨다.
5. 본 문서에서 **추후 확정**으로 표시한 항목은 별도의 디자인 시스템 논의를 거쳐 확정한다.
